# EquilibreSe

**EquilibreSe** é um aplicativo focado no bem-estar e autoconhecimento, com funcionalidades para o gerenciamento de hábitos, diário pessoal, meditação e relaxamento. O objetivo é ajudar o usuário a monitorar seu estado emocional, registrar reflexões diárias e participar de atividades de relaxamento para melhorar o bem-estar mental e físico.

## Pré-requisitos

Antes de rodar o projeto localmente, você precisará ter as seguintes ferramentas instaladas:

- [Node.js](https://nodejs.org) (recomenda-se a versão LTS)
- [Git](https://git-scm.com/) (para clonar o repositório)

### Instalando o Node.js

Se você ainda não tem o Node.js instalado, siga as instruções abaixo:

1. Acesse o [site oficial do Node.js](https://nodejs.org).
2. Baixe a versão LTS (Long Term Support) recomendada para seu sistema operacional.
3. Siga as instruções de instalação do Node.js conforme seu sistema.

Após a instalação, verifique se tudo está configurado corretamente executando os seguintes comandos no terminal:

```bash
node -v
npm -v
```
Esses comandos devem retornar a versão do Node.js e do npm instalados em sua máquina.

### Instalando o Git

Se você não tem o Git instalado, você pode instalá-lo seguindo as instruções do site oficial.

## Como Rodar o Projeto Localmente

### 1. Clonar o Repositório

Abra o terminal e clone o repositório com o seguinte comando:

```bash
git clone https://github.com/matheuscostabarbosa/equilibre_se.git
cd equilibre_se
```

### 2. Instalar as Dependências

No diretório do projeto, instale as dependências necessárias:

```bash
npm install
# ou
yarn install
```

### 3. Iniciar o Servidor Expo

Após a instalação das dependências, inicie o servidor do Expo para rodar o aplicativo localmente:

```bash
npm start
# ou
yarn start
# ou
npx expo start
```

Isso abrirá o Expo DevTools no seu navegador. A partir daí, você pode rodar o aplicativo em um emulador ou dispositivo físico. Para rodar em um dispositivo, basta escanear o QR Code exibido no Expo DevTools com o app Expo Go (disponível na Play Store ou App Store).
